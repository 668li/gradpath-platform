# Research 004：Phase 0 决策与开放项

> 来源：`delivery/三线爬取类目调研-触发点×痛点×证据闸-2026-09-12.md`（含红队 H1–H10）、`delivery/GradPath计划书-信息差伴随层-2026-09-12.md`、002 交付范式、001 证据闸实现。本 spec 不重复调研，只做决议转写与开放项登记。

## D1 · 源归口与配置形态

- **Decision**：源清单走 **yaml 配置 + 纯函数 + 2 样本**（002 范式）；事件入 `official_announce` 同归口，证据行走既有 `_fetch_log`。**09-14 用户指令：首条实施线=山东省考**（"先从山东省的这个开始"）；国考/广东线降为同范式复制对象。**不爬职位内容（09-14 重申）**：事件级检测，职位表仅"已发布+直链"外链卡。
- **Rationale**：002 已把该范式固化为"加线=改 yaml+纯函数+2 样本"的低维护纪律；信任锚 `_fetch_log` 是唯一留痕（宪法 1）。
- **Alternatives**：为 004 单建爬虫模块（否——重复建设）；全自动源发现（否——列表页自动发现三次实证失败）。

## D2 · 事件 vs 职位入库

- **Decision**：职位表只发**外链型情报卡**（标题+官方直链），内容不解析不入库。
- **Rationale**：宪法 2/3；09-06 职位表线全删的既有纪律；G1 类目表"不入库"口径。
- **Alternatives**：解析职位表建库（否——红线，且维护成本与合规风险双高）。

## D3 · 短窗事件的机制（H7 修正转写）

- **Decision**：G2（面试名单/调剂/递补/补录/公示，2–3 天窗口）走**"捕获即上站"**，不走提前量表；触发判据=正文命中+日期串命中。
- **Rationale**：短窗结构性无法用 T-3/T-1 量表（红队 H7）；09-14 决策后"推"改为"上站"，SLA 口径=捕获延迟，不变。
- **Alternatives**：提前量表（否——窗口早于量表周期）；人工盯（否——不可持续）。

## D4 · 转登假设与兜底（H8）— **09-14 已实测：部分成立，需执行期适配**

- **Decision（暂定）**：探针第一优先验证 gov.cn 静态全文页；失败走 manual_paste 值守（30 分钟人工贴原文，接《考公尖刀集·公告日 runbook》）。
- **实测（2026-09-14 20:20–20:35，本机只读 GET 低频、浏览器 UA；WAF/证书问题如实记录，不绕过）**：

  | 候选 | 结果 |
  |---|---|
  | `rsks.shandong.gov.cn`（山东人事考试信息网） | **NXDOMAIN 死链**（AliDNS 与本机解析均失败） |
  | 灯塔-党建在线首页 `www.dtdjzx.gov.cn` | 200 / 691KB；Vue+axios CMS，数据内嵌于 script |
  | 灯塔招考公告列表 `/web/dtdjzx/lygwyzkgg.html` | 200 / 8.1KB；列表数据仅在 script 内——`html_to_text` 剥离后正文 12 字符、无日期 → **不过证据闸日期条件**（但原始 HTML 含标题/URL/时间戳，**content_sha diff 检测可用**） |
  | 灯塔公告详情 `/web/dtdjzx/lygwyzkgg/{id}.html` | 200 / 10.6KB；DOM 含标题+时间（如 `2026-05-30`）+来源 → **机制上过闸**（raw ≥2KB ✓、日期在剥离后文本直接命中 ✓）；正文实体仍在 JS（DOM 正文约 132 字符） |
  | 山东人社厅 通知公告 `/channels/ch00330/` | 200 / 641KB **纯静态可读**（正文 47.8K 字符、155 个日期串）——但考录信息已迁出，无现役省考公告 |
  | 山东人社厅 2018 变更公告（权威存证） | `hrss.shandong.gov.cn/articles/ch00330/201812/efb39e3c-6281-450f-af31-2333d177b730.shtml`：**"自 2019-01-01 起，公务员考录全部信息变更至灯塔-党建在线发布"** |
  | `www.scs.gov.cn`（国家公务员局） | 证书主机名不匹配 + TLS 重协商；`-k` 取回 987B EdgeOne 机器人挑战壳页（`EO_Bot_Ssid`）→ **不可作 OFFICIAL 源**（不绕过） |
  | `bm.scs.gov.cn` | TLS 握手中断（复测；09-12 SPA 壳记录延续） |
  | `www.gov.cn` | **200 / 68.7KB 可达**（转登候选存续；转登栏目结构待 10/14 公告日实测） |

- **结论**：山东线自动路径 = 灯塔列表页 **diff 检测**（数据在原始 HTML 内）＋**详情页作证据源**（机制过闸）；`rsks` 从源清单移除。**国考线无自动 OFFICIAL 源可用**（scs 系 WAF/证书）→ 10/14 D-day 的 manual_paste 值守通道价值上升（spec 已备兜底）。
- **闸门语义发现（执行期决议项）**：证据闸正文判定 `html_to_text` 剥 `<script>`（`timeline_service.py:223`）——灯塔系数据在 script 内，列表页拒、详情页靠 DOM 时间戳过。内嵌 JS/JSON 数据的"正文"语义是否可接受，执行期定夺（当前闸门为机制判定）。
- **Rationale**：主站 bm.scs.gov.cn 为 SPA 壳（4276B，09-12 探针实测）；新华/人民网有全文但非 gov.cn 域（时间诚实口径不接受非官方域作 OFFICIAL 源）。
- **验收判据**：HTTP 200 + 正文 ≥2KB + 日期串归一化命中。

## D5 · 时效 SLA

- **Decision**：捕获延迟 ≤N 小时；**N 首周标定**（测首周实际捕获延迟分布后写回 yaml）；公告季窗口出日报。
- **Rationale**：计划书 Phase 2 原文"捕获延迟 ≤N 小时（N 为时效指标，首周标定）"。
- **度量口径**：t_capture − t_publish(可见最早公开时间)；首周用人工抽查抽样标定。

## D6 · 展示与通知口径（09-14 决策转写）

- **Decision**：主展示=站内（时间线节点引用+事件流）；订阅者 Notification 沿用 001 幂等与 INFO 配额；**不新增推送渠道，不做推送差异化**。
- **Rationale**：09-14 用户拍板（提醒/推送不做；公考雷达+官方渠道已覆盖纯提醒；个人主体无服务号权限）。调研依据见 `docs/综合调研v2-第一性原理与对抗审查-2026-09-14.md`。
