# GradPath 项目宪法（constitution）

> 来源：09-06 战略转向拍板 + 09-12 彻底再确认 + 项目约束红线 + 真相协议 + 部署风暴纪律。
> 一切 feature spec / plan 的 gate 以本文件为准；违宪必须在 plan.md 的 Complexity Tracking 里给出豁免理由并留用户拍板痕迹。

1. **零造假**：任何展示给用户的数据必须带来源（`source_url` + 采集时间 + 可信度），无来源的字段不得以"事实"形态出现。合成/推算值必须显式状态标签（如 `PREDICTED`），且推算值永不得冒充已确认。581 假进面线 = 本条的判例。
2. **定位红线**：产品核心 = 信息差供给 + 聚合 + 流程时间线伴随。不复活职位库（职位数据已全删、查询全外链）；不主打"搜→勾→能不能报 / 估分→档位"判定漏斗（辅助保留）；不做考研/就业线复制（红线 5 不复制战线）。
3. **合规爬取**：只抓官方公开页面与已授权源；低频率、单页触发优先、遵守 robots；WAF/403 如实记录不绕过（Phase-I 判例）。职位表内容不解析不入库，解析管道归档不删。
4. **时间诚实**：未来的官方日期没人知道。`OFFICIAL`=官方公告明文；`PREDICTED`=按上年节奏推算（界面标注"预测，公告后自动更新"）；`UNKNOWN`=空。提醒语义分级：PREDICTED 节点只允许试探式措辞（"预计近期，建议收藏入口"），断言式措辞（"明天截止"）仅限 OFFICIAL。负例测试必须穿到提醒文案生成层，防假绿。
5. **身份覆盖**：一切推荐/榜单/过滤须覆盖考研/考公/就业/在校身份面；考公功能先验证"身份相关过滤"生死线判据。
6. **推送纪律**：复用 Notification(type=reminder)+Server 酱；INFO ≤3 条/天配额；幂等键防重发。
7. **工程纪律**：真实数据零造假门禁走审核队列+溯源列；端口 8001(后端)/3000(前端) 约定；迁移前实测生产 `alembic current` 作 down_revision、单头自检；测试从 backend 目录跑 pytest；前端三绿(lint/vitest/build)。
8. **部署纪律**：全域禁 `reset --hard`/force-reset——分叉一律 worktree/clone 收敛（gp-converge），撤销用 revert 追加；发射前 gp-preflight 四闸（ff/磁盘/基础镜像/幻影 stamp）；改完必上产，冒烟走 HTTPS（80 已 301→quxianglab.cn），冒烟账号验证后删除。
