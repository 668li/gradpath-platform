# 职业测评：第一性原理拆解 + 对抗式审查（待拍板）

日期：2026-09-04 · 框架：kazike-toolbox 07 第一性原理 × 对抗式审查
背景：用户判「职业测评太无聊单一、一点护城河没有」，问怎么处理。旧测评处置 A/B/C 悬而未决；认识自己 V1（人生设计对话主线）刚上线。

---

## 一、拆解

### ① 已确认的基本事实（全部带实证）

- **F1 评分引擎是公域通用实现**：4 套测评 = Counter/均分 → 类型码 → 静态字典查文案 → 罐头职业方向（`assessment_service.py` 全文已读；题库硬编码无 DB）。任何人一天可复制。测评本身零专有内容——用户"没护城河"的判断在事实层成立。
- **F2 护城河机制已建成并部署生产**：`POST /api/assessment/interpret`（`assessment_interpret_service.py`）= 测评 × 真实专有数据（三路决策引擎/进面线/薪资前景/同分人群去向），每条带溯源，数据不足诚实降级。
- **F3 但前端零调用 interpret**：API client 已定义（`lib/api/assessment.ts:24`），全仓无任何页面调用。用户看到的结果页 = 类型码 + 静态摘要 + 罐头方向（`assessment/page.tsx:806-881`）。**护城河锁在抽屉里。**
- **F4 生产 assessments 表仅 2 行**（1 mbti + 1 holland，2026-09-01/02，疑似冒烟残留待核）。真实使用 ≈ 0。**"无聊"是假说，"没人用"是实测。**
- **F5 结果页霍兰德匹配职业卡硬编码 IT/数据味文案**（page.tsx:162-192"需要在技术深度与数据决策间保持平衡"等）——违反身份覆盖红线（考研/考公人群不是数据分析师）。
- **F6 人生设计 V1 已成"认识自己"新主线**（对话式、可续、S4 数据体检卡吃真实数据）。测评与它是同一职责（给决策收集输入）的两代交互形态。
- **F7 代码自己承认 4 套里 3 套对决策无贡献**：interpret 服务把非霍兰德测评降级为"不直接作为主判据"（`_interpret_other`）。学术效度上 MBTI 弱、大五好但与考研考公选路远、霍兰德与职业路径直接相关。

### ② 习惯性接受、未验证的假设

- **A1**"职业规划产品就该有职业测评"——竞品都有是行业惯例，不是从目标推出。
- **A2**"护城河要在测评工具里找"——护城河在专有数据+回传闭环（09-02 护城河审查已实证）；测评只是输入收集器。收集器不需要惊艳，需要准和便宜。
- **A3**"4 个体系=更全面=更好"——4 个通用测评 = 4 倍无聊 + 0 差异 + 3 个不喂决策。多即是少。
- **A4**"用户想知道自己是什么类型"——用户想知道"我能不能报、走哪条路"。类型码是手段不是目的。
- **A5**"把测评做漂亮能解决无聊"——最诱人的补丁方向，但 F4 说问题不在体验层。

### ③ 真正目标

"认识自己"在 GradPath 的职责 = 产出让报考决策更准的输入 + 制造"只有这个产品能告诉我"的时刻。北极星是报考决策，不是心理测量。

### ④ 资源与约束

已有：决策引擎/条件账本/进面线/同分人群/专业前景/22 skills/人生设计/BYOK。
约束：不造假、诚实降级、身份覆盖、开发资源有限、真实用户≈0（冷启动）。

## 二、输出

### ① 原方案只在修补表面的部分

- 给 4 套测评加题型/动画/减题量 = 表面补丁（没人用，做漂亮也不改变）。
- 引入第 5 套测评 = 表面补丁（更多通用 = 仍 0 护城河）。
- A/B/C"保留还是删除"之争本身困在"测评是产品"的框架里。第一性原理：测评是收集器，该问的是"收集什么、给谁用"。
- Phase B 的 interpret 方向正确，但"部署了没接前端"= 护城河仍是死代码（F3）。

### ② 从基本事实重新推导的新路径

核心反转：**不再把测评当产品卖，把测评当决策引擎的数据源。**

- **P1 把护城河从抽屉接到屏幕上**：结果页不再展示"你是 XXXX + 6 个罐头方向"，直接调 interpret 渲染"你的类型 × 你的专业 × 你的学校层次 → 可报岗位数 / 进面线稳不稳 / 薪资前景 / 同分人群去向"，每条带溯源。后端代码已写完，只差前端消费。
- **P2 收敛**：霍兰德为唯一默认测评（唯一直接映射路径的，F7），MBTI/大五/DISC 降级为选做或移出主导航。理由：F1+F7——保留 3 套不喂决策的测评 = 3 次说错话的机会（信任经济学）。
- **P3 与人生设计合流**：测评结果作为蓝图的一个输入源；"认识自己"主线是对话，测评是其中 5 分钟快速输入。

### ③ 路径成立的前提

- 前提1：用户档案已填专业/学校层次，否则 interpret 降级为"请补档案"（身份包持久化+登录预填已上线可缓解，冷启动空态仍是风险）。
- 前提2：专有数据覆盖用户专业（~55 专业映射+keyword 兜底+国考/省考真实数据）。不覆盖时=诚实空态，体验可能不如通用测评——这是该路径的真实风险。
- 前提3："类型×数据比纯类型有用"是推断不是事实，需真实用户确认。

### ④ 验证第一步（最小实验）

- **E0（半天）**：结果页接现有 interpret 端点，部署生产。护城河从抽屉到屏幕的最小动作。
- **E1**：看漏斗——测评完成率 → 结果页停留 → 点进决策引擎。若接了仍没人用，问题在上游（流量/入口），处置答案再变。
- 顺手修 F5（IT 味文案改身份覆盖口径）+ 核实 F4 两行是否冒烟残留、是则清理。

## 三、对抗式审查（逐条攻击）

| 攻击 | 判定 |
|---|---|
| "interpret 是护城河"→ 没接前端就是死代码 | **成立**。F3 实证。所以第一步是接线，不是新测评。 |
| "删 MBTI"→ 它是中文互联网最强传播货币 | 部分成立。但传播归分享闭环（已上线），可分享的应是"你的专属路径报告"（只有你能分享），不是"我是 INFP"（谁都能分享）。 |
| "接 interpret"→ 冷启动同分人群为空，用户看"数据不足"比通用测评更糟 | 部分成立。降级路径有三路决策+专业前景真实数据兜底，peer 只是增强；"诚实说没数据+引导回传"正是劝退卡的信任经济学打法。 |
| "收敛霍兰德"→ 48 题最长，无聊可能就是题量 | 表面成立（A5）。题量是体验层小修，不改变"没人用"的主矛盾。 |
| "测评=收集器"→ 48 题压成 3 个字母，信息量极低值得收集吗 | 成立但无害：价值不在码本身，在码×档案×真实数据的组合（interpret 已实现）；且测评是唯一不依赖 LLM/BYOK 的结构化自我报告输入。 |
| **最致命**：全部路径假设"有用户"，F4 实测真实使用=0，谈模块护城河是二阶问题 | 承认前提，反杀：正因没用户，每个模块按"用户来了帮不帮转化"裁决——接了 interpret 的结果页是唯一能让考研用户说"这站不一样"的页面，值得先做；4 套测评矩阵不值得。 |

## 四、处置选项（拍板用）

1. **方案一（推荐）**：P1+P2+P3 全做——接护城河上屏、收敛霍兰德为默认、测评并入人生设计蓝图。旧 A/B/C 的新答案 = "收敛为一个 + 接上真数据"。
2. **方案二（最保守）**：只做 P1+E0，4 套测评原样保留，先看漏斗再定收敛。
3. **方案三（最激进）**：测评入口整体下线，人生设计为唯一"认识自己"主线，测评降为档案页可选小工具。

## 五、追加（09-04 用户追问）：三套非决策测评的五个处置方向

"降级/移出"只是手段，把 MBTI/大五/DISC 当资产重新定价有五个方向：

- **方向一 各打各的工**：大五→备考执行参数源（尽责性C调计划强度、神经质N触发冲刺压力提醒；三套里唯一效度硬且可低成本复用的）；MBTI→纯传播/社区资产（0 用户前是期货）；DISC→24 题最短，当 2 分钟快速入口漏斗。对抗：没回答"没护城河"，只是给大路货找新工位。
- **方向二 自建融合测评**：公域题库抽相关项+考研考公情景题（"愿意实验室三年吗/接受写五年材料吗/家里供得起二战吗"）合成 ~20 题专有测评，护城河从"理论"转移到"题库×情景标定"。对抗：无信效度数据，只能诚实标"决策自我认知工具非心理测量"；成本中高。唯一正面造护城河的选项。
- **方向三 回传闭环类型维度**：类型×选择×回传→"同类型同分人群去向"（接护城河候选①）。对抗：0 用户时是期货；霍兰德一套可能就够当类型维度。
- **方向四 溶解进对话（釜底抽薪）**：无聊病根=问卷形态本身；题库拆单题嵌进人生设计访谈，测评作为产品消失、作为素材存活。对抗：可能打断已上线的阶段协议节奏；对话信号不如固定题库标准化，interpret 映射要重做。
- **方向五 删（钢人版）**：使用=0+不喂决策+三次说错话机会，删除的信任经济学论证最强。

**推荐组合（观点）**：四为主 + 一的大五分支 + 三记账；MBTI/DISC 独立问卷自然退役（不删代码，移出主线）。

## 六、追加（09-04 用户追问）：只保留霍兰德，测得准吗？

**答案取决于要求它准什么**：作为三路决策的方向软先验——够；作为"该考研还是考公"的判定——任何一次性自陈问卷都测不准（形态的理论天花板，非换题库可解）。

霍兰德单独扛的三个真实弱点：①48 题压 3 字母丢分辨率；②平 profile（六维分接近）人群 top-3 近似随机，现有代码只防"作答全同"不防"无区分度"；③只测兴趣，不测能力与价值观（考研考公决策最敏感的"舍不舍得/耗不耗得起"）。

补准确度四方向：
- **A 诚实降级（零成本必做）**：平 profile 检测→自动降置信+引导看真实数据（581 闸门/劝退卡同牌）。
- **B 霍兰德+大五 10 题短版（性价比最高）**：兴趣×特质正交双信号；大五尽责性喂学习计划执行层，TIPI 类公开短版仅加 10 题。
- **C 情景价值观题（方向二轻量版）**：5-8 道"舍不舍得"题，诚实标"非心理测量，是自我盘点"；补弱点③，通往专有题库护城河。
- **D 回传修正（理论真答案）**：测评给初值→行动→回传修正"同类型同分人群"统计。测评测不准是常态，有无纠错闭环才是分水岭（护城河候选①）。

**收敛后形态（观点）**：一份测评 = 霍兰德（48 或减至 24）+ 大五 10 题短版 + 平 profile 诚实降级；三套独立问卷退役；决策精度靠真实数据兜底、回传持续修正。
