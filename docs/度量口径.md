# D2 提醒实验度量口径（实验开局 2026-09-05）
发送数 = 当日 type='reminder' 的通知行数：
    SELECT count(*) FROM notifications WHERE type='reminder' AND created_at::date = (now() AT TIME ZONE 'Asia/Shanghai')::date;
续做率 = 昨日被提醒用户中，今日有 streak_records 行或今日有 micro_action_tasks 完成的比例。
判据：续做率较开关前 +10 个百分点 → 提醒扩到 4 类；无提升 → 停推送转降任务成本。
（表名 notifications/micro_action_tasks/streak_records 已实测；若 psql 实测对不上，以实测为准修正本文档并在 PROGRESS.md 记一句）

# 时间线伴随北极星口径（feature 001，speckit 001 FR8，2026-09-12）
条件完成率 = Σdone 节点 / Σ已到达提醒窗口的节点（分母只数有日期且 planned_date−7 天 ≤ 今日的订阅考节点，UNKNOWN 永不入分母——没数据不假装会完成率）：
    SELECT count(*) FILTER (WHERE f.status='done')::float / NULLIF(count(*),0)
    FROM t_exam_node_feedback f
    JOIN t_exam_node n ON n.id = f.node_id
    WHERE n.planned_date IS NOT NULL AND n.planned_date - 7 <= (now() AT TIME ZONE 'Asia/Shanghai')::date;
回传率 = 有回传行的已到窗口节点 / 已到达提醒窗口的节点（用户理提醒动没动手）：
    SELECT count(DISTINCT f.node_id)::float / NULLIF(count(DISTINCT n.id),0)
    FROM t_exam_node n
    LEFT JOIN t_exam_node_feedback f ON f.node_id = n.id AND f.subscription_id = n_sub.id_placeholder
    WHERE n.planned_date IS NOT NULL AND n.planned_date - 7 <= (now() AT TIME ZONE 'Asia/Shanghai')::date;
（第二条中的订阅维度以实测 SQL 为准，上线后由冒烟会话补全并记 PROGRESS.md；表名 t_exam_node/t_exam_node_feedback/t_timeline_reminder_log 来自 backend/app/models/exam_timeline.py 实测建表）
幂等/配额审计：SELECT tone, channel, count(*) FROM t_timeline_reminder_log GROUP BY 1,2;
——断言式（tone=assertive）行 join 节点后 date_status 必为 OFFICIAL，任何违例=宪法 4 事故，上生产后为周巡检 SQL。
