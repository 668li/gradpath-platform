# D2 提醒实验度量口径（实验开局 2026-09-05）
发送数 = 当日 type='reminder' 的通知行数：
    SELECT count(*) FROM notifications WHERE type='reminder' AND created_at::date = (now() AT TIME ZONE 'Asia/Shanghai')::date;
续做率 = 昨日被提醒用户中，今日有 streak_records 行或今日有 micro_action_tasks 完成的比例。
判据：续做率较开关前 +10 个百分点 → 提醒扩到 4 类；无提升 → 停推送转降任务成本。
（表名 notifications/micro_action_tasks/streak_records 已实测；若 psql 实测对不上，以实测为准修正本文档并在 PROGRESS.md 记一句）
