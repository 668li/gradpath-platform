> **背景**：服务器自带的 AI key 已欠费（上游返回 Arrearage），全站 AI 对话/洞察/复盘不可用。
> 你有两个选项，**二选一**：
> 1. **充值原 key**：去智谱开放平台（open.bigmodel.cn）给原 key 充值——服务器端零改动，充完即活。
> 2. **BYOK（自带 key）**：用你自己的任何一家 key，按下面 3 步切换——推荐，额度归你、模型你挑。

## BYOK 三步操作（生产站，约 2 分钟）

1. **进入设置**：登录 https://quxianglab.cn → 顶部导航「设置」→ 找到「AI 对话服务」卡片。
2. **选供应商并粘贴 key**：下拉选一家（智谱 GLM / DeepSeek / Kimi / 通义千问 / OpenAI / 自定义 OpenAI 兼容），
   粘贴对应平台的 API Key（各家取 key 入口见卡片内的直达链接）。保存。
3. **验证**：回到任意 AI 功能（AI 对话 / 测评解读 / 复盘）发一条消息——有正常回复即通。
   若报错「AI 服务账户或配置异常（上游鉴权/欠费）」= key 无效或欠费，换 key 重试。

## 技术细节（排障用）

- 配置存储：`PUT /api/user-llm-config`（base_url/model/api_key 三元组，按用户隔离）；
  平台侧状态查询：`GET /api/user-llm-config/platform-status`。
- 生效机制：`resolve_user_llm_override` 命中 BYOK 配置时跳过服务器配额（费用由你自己的供应商承担），
  全部 AI 调用点（对话/洞察/复盘/决策分析）经 ContextVar 中间件透传，共 42 个调用点零改动复用。
- 降级 UX（key 缺位时）：AI 对话返回 503「AI 服务未配置：请在设置 → AI 对话服务填入你自己的 API Key」；
  上游 401/402/403 返回 502「账户或配置异常」、其他上游错误返回 502「暂不可用」（R-10 已分流）。
- 免费额度过大站限流的提醒：glm-4.7-flash 免费档有分钟级限流（429），重试机制已内置（tenacity 指数退避），
  但高频使用建议任一付费档。
