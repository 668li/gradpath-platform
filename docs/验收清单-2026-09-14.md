## 一、验收总则：执行会话交“证据包”，我逐条实测复核

**执行会话交付时必须附**（缺任一件不进入验收）：

1. **改动清单 + `git show --stat`**：收敛/部署后必验产物内容（不是只看 "healthy"）；
2. **回归证据**：pytest 全量绿（行数级证据，如 1866 passed）+ `pre-commit run --all-files` 干净（自动修复轮后 add 全部被改文件）；
3. **生产实证**：生产域名/容器内的实测输出（grep 命中/未命中、curl/浏览器冒烟），**冒烟必须绑本次特有断言**（不是“页面能打开”）；
4. **数据处置痕迹**：删除带备份位置、drop 迁移挂台账、向量层对账（如涉及）；
5. **部署痕迹**：bundle→scp→update_from_bundle.sh 记录 + gp-preflight 四闸输出。

**我的复核动作**（不采信转述）：关键项我自己复跑命令/直连生产抽查；与记忆/台账对账；发现不符→退回并列出具体不符项。**验收通过才进“下一步方向”。**
