## 四、仍存在的痛点（现象 + 归因）

1. **决策实验室第 3 步矩阵计算崩溃**（严重度：高）| 现象：权重配平后点"计算加权得分"，无论先填分还是后填分（5 种顺序复现），必崩"页面渲染遇到问题：Cannot read properties of undefined (reading 'toFixed')"，错误边界接管，返回列表后**草稿全部丢失**；单标准 100 权重时则不出打分表。decision-lab 页面对 `?decision_id=` 参数完全不响应，"继续分析"落进空实验室。| 归因：**机制断**（复活路由时矩阵组件的计算函数未兜空值；向导状态不落库）。建议：计算前判空、向导逐步落库、decision_id 预填决策标题与选项。
2. **onboarding 身份字段仍缺 + AI 诊断零反馈**（严重度：中高）| 现象：4 步无学校/专业（用户填不了北邮/临床，导致看板"同路人镜像"拿"考研 100%"给我这个就业向用户、AI 管家反过头催补画像）；方向仍单选，没有"考公"，"家望考公+自己想就业"无法表达；点"生成 AI 诊断报告"后 60 秒无 loading、无失败文案、无自动降级。| 归因：**交互缺陷未修** + AI 欠费下缺前端状态反馈。建议：第 2 步加学校字典/专业字段；诊断按钮加 loading+超时自动降级为"稍后再生成"路径。
3. **决策中心"新建决策/创建决策"按钮无响应**（严重度：中）| 现象：空状态下点两个入口，无弹窗、无跳转、无 API 调用（仅埋点上报），普通用户会以为坏了；唯一可用路径是侧边栏进决策 OS 手填。| 归因：**机制断**（按钮事件未绑定/弹窗未挂载，静默失败）。建议：绑定到决策 OS 预填文本，或恢复内嵌创建表单。
4. **面经库与专业仍零相关**（严重度：中）| 现象：12 道高频题仍是短链服务/HTTPS 握手/秒杀系统等 IT 题，临床医学生唯一可用的是行为面试 5 题。| 归因：**数据少**（题库无专业维度，未动）。建议：按行业分组，先补医疗/会计两组。
5. **AI 对话检索覆盖窄**（严重度：低中）| 现象："临床医学考研复试线多少分"在库内有 68 条记录的情况下仍"暂未找到相关资料"。| 归因：**机制断**（降级检索只索引情报类内容，未接分数线/研招目录/薪资数据源）。
6. **家庭对话弹药未个性化**（严重度：低）| 现象：我填"去医院规培岗"，5 条话术全部围绕"互联网大厂 30-45 万 SP/SSP"展开，无一字提医疗行业。| 归因：**模板硬编码**（互联网vs考公单一场景）。建议：按用户填写的选择注入对应行业数据（就业市场库里有现成的卫生行业薪资）。
7. **空壳模块仍在**（严重度：低）| 现象：看板"职业星系/职业匹配指数 0/100"对零行动新用户仍是空壳展示；失败案例 0 条但推荐位仍推"看看别人的弯路"。| 归因：**数据少**（诚实标注了但未收纳）。
