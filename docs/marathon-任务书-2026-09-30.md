## 红线与打法（09-29 复盘 12 条，动手前 30 秒过筛）

**停止做**：
1. 停止用 `rev-list --count` 做收敛判据（cherry-pick 镜像恒噪音）——换 `git diff <A>..<B> --name-only` 内容级判据；**收工固定闸：`git diff <deploy-ready>..<deploy-rebased> --name-only` 归零检查**。
2. 停止对子代理配额/并发错误做第 3 次重试——失败 2 次即切自执行。
3. 停止凭记忆猜表名/列名/响应结构——先查 `information_schema` / response_model（一行 ssh 命令，固化为动手第一步）。
4. 停止在组合 Bash 命令里夹带 .py 写操作——一律 Write/Edit 单发。

**继续做**：
1. 部署四件套：converge→preflight→nohup 绝对路径→轮询（13 连胜配方）。
2. 导入五步法：dry-run→抽验 N/3→备份表→入库→生产复核（4 个导入脚本全幂等可重跑）。
3. not_found 如实 + 官方 source_url 红线（无源不入库）+ 抽验 N/3 后批量采信。
4. 挂账不过夜：对抗审查产出当场立项当场销账。

**新增做**：
1. 新数据源先 1 分钟形态探针（HTML 表格 / JS 壳 / 图片表三选一）再定路线。
2. 解析器先读表头行定列序（勿拿首校样本先入为主）；PDF 缓存留档作证据。
3. "一校打穿→复用"：先全链打穿一校建样板，其余按配方增量；代理配额受限时先打样板再人工接管。
4. schema 速查固化为习惯动作。

**已知坑速查**（一期实录）：chsi 图片下载扩展名拼接 bug（_0png）；聚合站（eol/kaoyan.cn）正文=JS 壳/图片表；yanzhao 唯一索引=(uni,major,year) 不含 degree；B0 增删平衡只认 crawler_ 前缀；Mimosa 拦 scp .py 入容器 + 拦变量 URL 爬取脚本（爬取类不落库脚本走人工清单+内联执行）；update_from_bundle.sh 只认绝对路径。
