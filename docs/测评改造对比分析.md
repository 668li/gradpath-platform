# 现有职业测评 vs 卡兹克人生设计：对比分析与去留建议

日期：2026-09-02
背景：用户指出「现有职业测评太单调、没新意、无护城河，不如内置卡兹克的人生设计 skill」。旧测评去留 = 先分析再看。

---

## 一、两套东西到底是什么

### 现有职业测评（Holland / MBTI / BigFive / DISC）
- 一次问卷（24~50 题）→ 纯规则零 LLM 算分 → 得出一个**类型编码**（如霍兰德 RIASEC 三码）和几条**推荐方向**。
- 后端已做 _validate_answers 完整性校验 + 反作弊单一模式警示；B4 已灌进副驾驶上下文。
- **护城河**（已完成并部署的 /assessment/interpret）：类型×专有数据（专业/学校层次/应届/进面线/薪资/同分去向）→ 专属报考路径解读。

### 卡兹克人生设计（12-life-design，斯坦福人生设计）
- 一个**多轮深度对话**：4 阶段（你在这里→你的指南针→寻路→摆脱困境与创造可能），一次一问（主问题 6~9 个），交互 30 分钟以上。
- 维基：健康/工作/娱乐/爱四个仪表盘 + 真问题 vs 重力问题 + 三个五年奥德赛计划 + 8000~12000 字《个人人生设计蓝图》。
- 产出是**叙事性蓝图**，不是编码。本质是 LLM 对话式教练，不产出结构化分数。

---

## 二、核心差异（一张表说清）

| 维度 | 现有四套测评 | 卡兹克人生设计 |
|---|---|---|
| 形态 | 一次性问卷 → 结构化分数 | 30 分钟多轮对话 → 叙事蓝图 |
| 数据依赖 | 纯规则，可零 LLM 离线跑 | 必须 LLM，多轮，贵、慢 |
| 产出 | 类型码 + 推荐方向（结构化、可被程序消费） | 自由文本蓝图（几乎不可被程序直接消费） |
| 覆盖人群 | 泛职业人群，题量固定，门槛低 | 需要愿意长篇对话、有自我反思意愿的用户，门槛高 |
| 护城河 | 已有=/assessment/interpret 类型×专有数据→专属路径 | 方法论稀有（斯坦福人生设计），但**内容可被任何通用 LLM 复刻**，无专属数据 |
| 与决策引擎衔接 | **已接通**（见下） | 目前零接通，需另建 |

## 三、关键事实：现有测评不是能随手丢的排管，它已织进产品 6+ 处

替换前必须先知道这些消费点（全部已核实行号）：

1. **`recommender` 弱项召回**（recommender.py:137-148）：霍兰德缺失维度 → 强推对应学习方法 tag（权重 2×5）。
2. **`proactive_insight` 主动洞察**（proactive_insight_service.py:118-126）：把测评编码+推荐写进「该用户适合做什么」的主动提示。
3. **`path_conflict` 冲突检测**（path_conflict_service.py:95-160）：`recommended_directions` 映射成赛道，与用户现状决策比 → 判断「测评推荐 vs 现状冲突」，有冲突给调解建议。
4. **`learning_methods` 学习方法推荐**（api/learning_methods.py:115-126）：测评码 → 学习 tag。
5. **`user_context.build_context_prompt` 副驾驶**（user_context_service.py:279-287）：测评编码+摘要+推荐方向进副驾驶系统提示。
6. **`ai_butler` / `personal_intel` 能力盘点**：把「做过测评」当用户自我认知/个人智能的一张牌（assessments 计数参与评分）。
7. **`/assessment/interpret` 护城河本体**（assessment_interpret_service.py:149-239）：霍兰德类型 → 三路导向强度（研究型深造 4/就业 3/考公 1），结合专业/学校层次/应届 → 调用 path_decision_engine 出专属路径。这是别人只给类型、我给专属路径的核心。

**结论：`result_code` + `recommended_directions` 是一组被 6+ 处消费者依赖的结构化契约。** 直接删掉它会连带折断弱项召回、冲突检测、学习方法推荐、副驾驶、主动洞察、个人智能——不只是「单调」。

---

## 四、护城河的真实对比（这是用户最关心的点）

- 现有测评的护城河**不在测评本身**，而在 `interpret`：类型×专有报考数据→专属路径。这个别人抄不走（数据是 581 溯源闸门+真实慢采集攒出来的）。
- 卡兹克人生设计的方法论（斯坦福人生设计）**可被任何通用大模型复刻**——用户在 ChatGPT 里贴同一个 prompt 就能得到几乎一样的对话。它没有任何 GradPath 专有数据可以依赖。单独内置它 = 给通用能力付费，不构成壁垒。
- **如果要做卡兹克人生设计，护城河只能来自「人生设计产出 → 接回报考决策数据」这一步**：把蓝图里定下的方向，翻译成「基于你的进面线/学校层次/专业前景的真实可执行路径」。这正好和现有 interpret 的取向一致。

---

## 五、关键矛盾（必须让用户拍板）

卡兹克人生设计（多轮 LLM 蓝图画）与现有 interpret 护城河（纯数据零 LLM 专属路径）是**两种范式**：

- 蓝图画是**开放式的**：产出个人愿景、五个方向、原型行动——不保证落在「报考/考公/就业」三路可量化框架里，难以和决策引擎自动对齐。
- interpret 是**收敛式的**：把人钉到 R还能/升学/考公的具体进面线、薪资、同分去向上。

两者能衔接，但衔接点要**现做**：从蓝图文本里抽取「阶段目标+方向倾向」→ 匹配到三路 → 灌回 interpret / 路径卡。这一步需要 LLM 抽取（蓝图是自由文本），会引入一点幻觉面，和「诚实降级/零造假」纪律有张力，需要加溯源标注。

## 六、去留建议（三选一）

### 方案 A：并存 —— 推荐
- 现有 4 测评 + interpret（纯数据、结构化、已织入 6 处）**保留**，它是地基和护城河本体。
- 卡兹克人生设计作为**独立交互页加入**（用户已拍板独立交互页），定位「深度自我认知 / 方向划线」，是测评的**上探层**（先想清楚方向，再用 interpret 把它落到可执行路径）。
- 衔接：独立页产出蓝图 → 一键把「阶段目标/方向倾向」导入 interpret，变成专属路径卡。
- 优点：不动地基，护城河仍在；给用户多一层别人给不了的深度对话；风险最小可回滚。
- 缺点：两套入口，需要说明定位别让用户困惑。

### 方案 B：替换（现有 4 测评下架）
- 把 holland/mbti/bigfive/disc 全下掉，改成人生设计。
- **不建议**：会连带折断 6+ 消费者（弱项召回/冲突检测/学习方法/副驾驶/主动洞察/个人智能全失去结构化输入），且失去 interpret 专属路径护城河；而人生设计本身可被通用 LLM 复刻，净护城河反而下降。

### 方案 C：并存 + 收敛对齐（在 A 上加强，工作量最大）
- 在 A 基础上，把奥德赛计划里的方向用 LLM 提取 → 结构化映射三路 → 自动和 interpret/进面线对账，冲突时提示。
- 这是「蓝图 → 可执行」的完整闭环，护城河最高，但要处理蓝图自由文本→结构化映射的幻觉面与溯源，需加闸门。
