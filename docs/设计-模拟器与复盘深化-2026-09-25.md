## 一、路径模拟器重构：「伪精确计算器 → 真数据胜率推演」

### 1.1 诊断结论（保留有效）

`docs/诊断-路径模拟器实测体验-2026-09-19.md` 判死的是"10 年薪资/满意度预测"范式：站内零纵向回传数据，
任何 10 年模拟在零造假红线下只能输出合成公式数字。**本重构换范式，不是修 UI**：

- 旧：`10 年后月薪 23,000、满意度 7.2、净资产 41 万`（编的精确数）
- 新：`目标层次院校报录比中位 8:1（P25–P75 5:1–13:1，N=214）；你的预估分 350 高于该层次 68% 院校近三年复试线（N=190）`（真实分布统计）

### 1.2 数据支撑（全部站内现役真数据，逐字段核过）

| 路径 | 表 | 字段 | 统计口径 |
|---|---|---|---|
| 考研 | grad_school_intel | admission_ratio("15:1"字符串→解析数值)、score_line、background_discrimination、school_tier | 按 school_tier 聚合分位数+N |
| 考公 | gwy_score_line | min_score、year、batch | 按地区(bureau/dept_name 前缀)或全国聚合 P25/P50/P75+N |
| 就业 | salary_benchmarks | salary_min/median/max × city × experience_level(entry) | 城市×行业过滤后直接算带 |
| 就业 | market_data | 行业薪资带+source_url | 宏观参照 |
| 三线共通 | t_exam/t_exam_node | 12 环节 date_status 三态 | 过程时间线骨架 |
| 回传(远期) | outcome_reports | build_peer_destinations 已有 | 样本 0 时诚实降级（复用现成实现） |

### 1.3 后端设计（重写 backend/app/api/career_simulator.py）

请求：`{paths: [{name, path_type(grad|civil|career), target, city, estimated_score?}], }`（1–3 条）

每条路径输出（**每个数字带证据链**）：

```
verdict:       {headline, badge(favorable|medium|tough), analogy}   ← 由百分位映射，附直白翻译
metrics:       [{label, p25, p50, p75, unit, sample_size, source_table, has_data}]
your_position: {metric, percentile, your_score, ref_distribution}    ← 分数在真实分布中的百分位
combo:         {reach, base, safe}    ← 冲稳保三档（由百分位阈值推导，输出组合健康度，不给唯一最优）
timeline_ref:  [{stage, date_status, date?}]   ← 该路径关键节点（有订阅给真日期）
honest_gaps:   [...]   ← 明确声明无数据维度（如"满意度/10 年轨迹：无回传样本，不做预测"）
peer_destinations: {...}   ← 仅考研且传了分：复用 build_peer_destinations（0 样本→has_data=False 诚实占位）
```

纪律：
- **无单点预测数**。满意度/净资产/10 年曲线/🏆推荐排序全部删除。
- 样本量阈值：任何统计 N<5 → has_data=False + 一句话说明，不硬算。
- 百分位 = 真实分布统计（"近三年 68% 复试线低于你的分"），不是模型概率。
- estimated_score 变化 → 前端重调 simulate（分位重算，低成本天然敏感度）。

### 1.4 前端设计（重写 page.tsx，砍 1207 行巨石）

结构：配置区（路径类型/目标/城市/预估分滑杆，1–3 条对比）→ 结果区：
1. verdict 徽章卡（三色+人话翻译）
2. 分布图（recharts：区间带+你的位置竖线）
3. 证据链折叠卡（每个数字的 N+来源表）
4. 冲稳保组合三卡
5. 敏感度滑杆（拖分重算）
6. 时间线节点条
7. 诚实缺口卡（明说哪些不做+为什么）

删除：computeMatchScores 伪匹配度、DUAL_TRACK 双轨文案、90 天静态蓝图、WhatIfSection（配置区已支持多路径对比，消除重复填报）。
保留：TestDriveSection（Forage 式试驾，唯一对齐模块）+ 补 `id="test-drive"` 修死锚点。
导航/命令面板/各页深链指向 /career-simulator 本身，路径不变不破链。

## 二、复盘功能深化（006 落地 + 调研增强：「四段式闭环 + 原则沉淀库」）

### 2.1 流程（业界六领域同构共识，AAR 时间铁律：一半精力在"下次怎么办"）

```
0 选情境+定预期   1 事实回放(自动)    2 AI 引导反思        3 提炼原则            4 Try 行动卡
 (类型路由:        (replay 四源聚合,   (AAR 四问逐问+双我    (if-then+场景标签,    (≤3 条,带触发场景
 KPT 3min/         零 LLM 零造假)      思维+最尖锐反驳,      入库+同步            +复审日期;下次复盘
 AAR 深度)                             教练式一次一问)       user_memory)         开场先复审上次的)
```

### 2.2 数据模型（一次 Alembic 迁移）

1. `MemoryFactType` PG enum 加 `principle`（ALTER TYPE，006 原设计）
2. 新表 `retro_principles`（原则库真相源，含状态机）：
   user_id / trigger_scene(if 条件+场景标签) / action(then) / rationale(why?) /
   status(draft|verified|invalid) / verify_count / source_retro_id / source_snapshot(JSONB) /
   next_review_at / is_active
3. 新表 `retro_actions`（Try 行动卡）：
   retro_id / user_id / content / trigger_scene / status(pending|effective|ineffective|not_met) /
   review_due_at(+14d) / reviewed_at / review_note / principle_id?(验证有效→升级原则)

### 2.3 API（api/retrospectives.py 扩展，鉴权同现状）

- `GET /replay?start&end` — 四源聚合（节点回传/职业事件/条件缺口/行动钩子），纯 DB
- `GET/POST /principles` — 原则库；创建时同步写 user_memory_facts(principle, source=user_provided)
- `POST /principles/{id}/verify` — 复审裁决：effective→verified+1 / ineffective→invalid(可修订) / not_met→顺延
- `GET /actions/due` + `POST /actions/{id}/review` — 行动卡到期复审（留存钩子）
- `POST /reflect` — AI 教练引导反思（一次一问、先情绪后归因、双我思维、魔鬼代言人）
- `POST /principle-draft` — 从复盘提炼 if-then 原则草稿（空话闸：拒绝"要更努力"类）

### 2.4 注入闭环（回答"下次再发生怎么办"）

- `chat_service.build_user_context` 新增【个人原则】段：active 原则 top5
  （verified 优先），格式含场景标签+验证次数 → AI 在类似情境自然引用
- 新建复盘第一屏：有到期行动卡 → 强制先复审"上次说要试的 X，结果如何？"（KPT Try 复审+M&M 开场核对）

### 2.5 范围裁剪（不做，挂二期）

半衰期浮现流(Readwise 式)、情绪层独立路由(并入 reflect prompt)、跨复盘模式总结、
团队复盘、premortem 独立页（Decision OS hypotheses 已有近亲，接口留 source_retro_id 即可）。

## 三、调研要点（两轮外部调研的支撑结论）

**模拟器**：五分位+样本量标注是 Levels.fyi/fire-calculator 跨行业共识；历史回测优先于随机(cFIREsim)；
冲稳保组合替代单点最优(CollegeVine+公考雷达双验证)；敏感度滑杆(fireplanner)；概率三色徽章+日常类比
(CollegeVine/ainumbers)；节点级证据标注(PathPilot)。

**复盘**：四段式流程六领域同构（AAR/联想四步/KPT/GRAI/ORID/4F/M&M/Edgewonk/NASA LLIS）；
AAR 50% 时间给"下次怎么办"；原则条目=触发条件+行动+来源案例三要素(Dalio/NASA/错题本)；
Try≤3 带复审日期(KPT)；开场复审上次行动(M&M/KPT)；事件触发递原则而非等检索(NASA GAO 58% 教训)；
反思 15 分钟/天=成绩+22.8%(Di Stefano 实验)；AI 当教练一次一问(review-skill)。
