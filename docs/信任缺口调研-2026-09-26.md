## 一、总诊断

**信任崩塌的根源不是"数据少"，而是承诺与兑现的差值。** 首页每喊一句，库里就有一处对不上的账：

| 首页承诺 | 兑现实况 | 判定 |
|---|---|---|
| "替你盯信息差，**准时推你一把**"（H1） | 推送链路 0 行运行史（t_timeline_reminder_log=0、订阅 0、通知全站 1 条） | **无支撑** |
| "**AI 问答只基于库内真实数据回答**" | AI 对话一发消息即 500（0.3s，dashscope Arrearage 欠费） | **可证伪** |
| "考研 · 就业 · 在校，**决策伴随全覆盖**" | kaoyan_news/grad_scoreline_records/employment_data/posts/qas/failure_cases 六表全 0 | **无支撑** |
| "**每个数字都可溯源**"（决策引擎页） | 考研路对任何专业必出"暂无分数线数据"（底座 0 行），没数字可溯源 | **空转** |
| "对比考研 / 考公 / 就业**三条路**" | 后端已是两路，前端三处仍喊三路，recommendation 还指路已删除的"考公卡片「岗位分析」" | **名不副实** |
| "流程时间线伴随 · 上线中，注册后可先行体验" | t_exam 3 场全是**已退役的考公线**（2026国考/广东省考/2027国考），无任何考研节点 | **承诺无支撑** |
| "每条情报连上官方来源" | 信任锚橱窗 150 yanzhao+15 intel **全部带源**；但 106 条未验证 bilibili 帖以 approved 状态可见 | **部分兑现** |

**存量硬通货（信任的本钱，被埋没）**：信任锚橱窗 165 条全带源（全站唯一 hard asset）、专业前景可聚合真数据（market 1217+companies 1693+salary 1873）、就业路引擎窄面能出带源结论（广东 5 校就业率带 career.szu.edu.cn 源）、决策实验室纯规则矩阵可用、PREDICTED 标注诚实、无数据量吹牛、ICP 在。

## 二、TOP 信任杀手（双代理交叉验证，按杀伤力排序）

### T1. AI 全线 500 —— 根因已定位：dashscope 欠费（Arrearage）
- 实测：`POST /api/chat/.../messages` → 500，0.3s 失败；容器内最小复现返回
  `{"error":{"code":"Arrearage","message":"Access denied...overdue-payment..."}}`（key 认证通过、payload 合法、model=qwen-flash 有效——排除参数/模型名问题）。
- **连带熄火的链**：AI 对话、决策实验室三步（预验尸聚类/红队/综合分析）、AI 决策分析、决策回溯分析（decision_journal_service.py:84）、证据外部核查（503）。
- 技术次生坑：`ai_service.py:128` raise_for_status 吞掉响应体（日志只见 400）；dashscope 把欠费包装成 400 而非 403；`chat.py:133` catch-all 把 4xx 转 500 误导排障。
- **唯一要花钱的一条**。BYOK 基建已在（全站 42 调用点），充值或开 BYOK 即点燃。
