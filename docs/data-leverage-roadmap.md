# 数据杠杆化路线图（2026-08-16）

> 结论先行：**加工（证据链/评分/审核）是护城河，获取侧应全部换成杠杆。**
> 爬虫只留给「无杠杆区」。这一步做完，每周省下的爬虫时间就是别人抄不走的复利。

## 一句话定位（ljg-rank 降秩结论）

**给三岔口的学生，做可被信任的去向决策，并陪他执行到位。**

三根护城河柱子：
1. **信任稀缺** —— 可信度本身是产品（裁判不能由球员兼任，巨头结构性做不了）
2. **决策视角** —— 考研/考公/就业是一次人生决策，不是三个市场（竞品按赛道切财报，动不了）
3. **行为闭环** —— 数据随用户生命周期复利

## 2×2 操作矩阵（目标：右上角「裁判型」）

```
加工深度
 信任资产 │  ● 起点（自爬×深加工 = 苦力裁判）   ★ 目标（订阅×深加工 = 裁判型）
        │       —— 获取烧命                        —— 时间换加工
 拿来就用 │  聚合站（无护城河）                  ⚠️ 下滑陷阱
        └──────────────────────────────────────────→ 来源杠杆
            自建爬虫                          RSS / 公开API / 开源数据集
```

纪律：**有杠杆通道的源绝不自爬；但每个源必须过证据链这道闸**（否则滑向右下角与聚合站无异）。
